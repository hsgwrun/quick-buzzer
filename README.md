# QUICK BUZZER

部活やイベントで使える、シンプルなブラウザ用早押しブザーです。

## 使い方
1. リポジトリの **Settings → Pages** を開きます。
2. **Deploy from a branch** を選び、Branch を **main**、フォルダーを **/(root)** にして保存します。
3. 公開されたURLをPCのブラウザで開きます。
4. **スペースキー**または画面の **BUZZ** ボタンを押すと、丸が表示されて音が鳴ります。
5. 次の問題に進むときは **リセット** を押します。

## 機能
- スペースキーで即時反応（キーリピートは無視）
- 押された後はリセットまで入力をロック
- 効果音の ON / OFF
- 全画面表示
- 外部ライブラリ・サーバー不要

音声はブラウザ内で生成します。
